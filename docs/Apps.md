# Apps

Interesting projects. This checkout does not install them.

## Linux

### [Dusky](https://github.com/dusklinux/dusky)

A small Arch + Hyprland setup. Settings, keybinds, wallpapers, and a hardware-specific kernel compile live as scripts and TUIs you run when you need them, instead of always-on services.

### [Hyprland plugins](https://hypr.land/plugins/)

The plugin directory for the Hyprland compositor: layout, design, and quality-of-life plugins.
